# CURSORGEN-41001

Dedicated 666PFS child for creating, developing, packaging and restoring custom Windows cursor sets.

Current baseline:
- LYVRA neon character cursor design
- 32 / 48 / 64 / 96 px sets
- static CUR plus animated ANI roles
- Windows batch launchers and PowerShell installers
- reversible per-user Windows cursor installation

This child is functionally separate from CURES-16001. Existing child identities must never be reused based on name similarity alone.
