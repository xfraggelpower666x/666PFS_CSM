# CURSORFRAME-42001

Dedicated 666PFS child for the general offline Windows cursor generator framework developed in this chat.

Scope:
- fully offline personal Windows desktop tool;
- import and audit existing cursor packs;
- generate CUR and ANI resources;
- multi-size 32/48/64/96 cursor output;
- role and hotspot editing;
- Windows cursor installation and direct activation;
- versioned backup, restore and readback;
- no Cloudflare, no account, no telemetry.

This child is functionally separate from both CURSORGEN-41001 and CURES-16001.
